# Quiz reward administration — 1 November 2026

The Quiz Manager now has manual daily-cap and per-partner-quiz policy controls, backed by manageQuizRewardPolicies. Administration defaults paused via PERKSPHERE_QUIZ_ADMIN_ENABLED. No setting, rate, partner credential or payout gate was enabled by development.

The gateway requires rules.manage permission, derives the signed admin actor from the session and rechecks permission/session before dispatch and before returning success. The fixed Linux admin route is /v1/perk-sphere/quiz-rewards/admin. It is a candidate route, not yet mounted on production. Do not enable the Base44 switch until the reviewed Linux schema/routes are installed and available.

Global caps and quiz policies use version conflict checks. Enabling a quiz requires an active verified partner, a published eligible partner quiz, a matching question-content review digest and enabled daily limits large enough for the configured award. HTTPS content references must belong to that partner's domain/subdomains; YouTube is excluded. A null review digest can only disable an existing policy, including when its source becomes ineligible. Rules-management approval is an operator decision, not independent proof of human activity or video viewing.

Changes and before/after admin audit records are one database transaction. An audit failure rolls back configuration. Only confirmed rolled-back deadlock/lock-timeout transactions may retry; a lost commit acknowledgement never retries the write. The interface discards uncertain results and requires an explicit reload, rather than automatically resubmitting. Focus, visibility and account changes clear stale editing state; staff identity is checked around each request. The pure response contract rejects foreign quiz previews, wrong next versions and expanded/private data.

Partner quiz creation is supported through the existing draft-only create/publish flow. Partner UUIDs are public references, not secrets. YouTube IDs/URLs are normalized to backend-compatible canonical URLs. Blank choices cannot be filtered out because that would move the correct-answer index; malformed answer keys now fail validation. Each draft receives independent arrays. Neither creating nor publishing a quiz enables its rewards. Existing attempts are never backfilled.

Verification: 387 main-app tests, 525 API offline tests and 20 isolated quiz MariaDB cases passed. Main build/lint and parsing of 143 backend files passed. Database cases include same-member replay, cross-quiz daily cap races, lost commit acknowledgement, concurrent policy revisions, changed review digest, audit rollback and actual service-HMAC signed admin/member HTTP paths with synthetic credentials. No real member, quiz, payment, policy or provider operation was exercised.

The administration interface does not complete member quiz payouts. The existing member grader, question/list/history contracts, gateway routing and result display still need their coordinated payout integration; the production quiz grader still issues zero. Linux deployment, selected production terms, abuse/content review and genuine member/mobile acceptance are still required before payout activation.
